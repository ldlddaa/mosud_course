## Задание

Из таблицы olist.order_items выбрать позиции заказов,
у которых цена от 100 до 500 включительно,
а стоимость доставки меньше 50.

Вывести order_id, product_id, seller_id, price.

## Исходное отношение и атрибуты

R = olist.order_items.

Используемые атрибуты:
- order_id — идентификатор заказа;
- product_id — идентификатор товара;
- seller_id — идентификатор продавца;
- price — цена;
- freight_value — стоимость доставки.

Обозначения:
- σ — выборка строк по условию;
- π — проекция на выбранные столбцы.

## Реляционные выражения

Исходное выражение:

π_{order_id, product_id, seller_id, price}(
  σ_{100 ≤ price ≤ 500 ∧ freight_value < 50}(R)
)

Разделение условия на две последовательные выборки:

π_{order_id, product_id, seller_id, price}(
  σ_{freight_value < 50}(
    σ_{100 ≤ price ≤ 500}(R)
  )
)

Раннее исключение ненужных столбцов:

π_{order_id, product_id, seller_id, price}(
  σ_{freight_value < 50}(
    σ_{100 ≤ price ≤ 500}(
      π_{order_id, product_id, seller_id, price, freight_value}(R)
    )
  )
)

Переименование атрибутов для задания не требуется.
В SQL имя filtered_by_price задаётся подзапросу через AS.

## Результаты и выводы

Отбор по двум условиям одновременно и две последовательные
выборки дали одинаковый результат: EXCEPT ALL в обе стороны
обнаружил 0 различий.
Раннее исключение ненужных столбцов сохраняет результат,
поскольку все столбцы для фильтрации и итогового вывода оставлены.
Обычный SELECT вернул 34 311 строк, а SELECT DISTINCT — 32 180,
то есть DISTINCT удалил 2 131 повторную строку.
Повторы возможны, поскольку разные позиции одного заказа
могут совпадать по всем четырём выбранным атрибутам,
но различаться по исключённому order_item_id.
В классической реляционной алгебре проекция устраняет дубликаты,
поэтому ей соответствует SQL-запрос с SELECT DISTINCT.
